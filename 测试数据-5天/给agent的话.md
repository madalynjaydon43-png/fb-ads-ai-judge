# 任务说明（这份可以整份转发给被测方）

## 任务

下面是 8 条 Facebook 广告的 **5 天逐日数据**（CSV，广告级粒度，28 列）。
请对**每一条**给出判断。

**输出格式**：JSON 数组，每个元素形如

```json
{"name": "广告名称原文", "action": "increase_budget|decrease_budget|pause|observe",
 "reason": "理由，必须引用具体数字"}
```

硬性要求：

- **一条都不能少**：8 条输入必须对应 8 条输出，不能合并、不能跳过。
- 不需要动作的也要输出，`action` 填 `observe`。
- `reason` 里**必须引用具体数字**（花费、点击、单数、频次、漏斗各环的通过率），
  不要写「表现良好」「需要优化」这类没有数字的话。
- 只输出 JSON 数组，不要任何前缀文字或解释。

## 读数据前请注意

文件里有几列是**「决定别的数字怎么读」的口径列** —— 它们不参与计算，
但不看它们就会把结论读反。请自己先识别并读它们（列名是中文，含义需要你判断）。

数据文件：`模拟数据_前5天.csv`（同目录）
